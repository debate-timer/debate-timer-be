Debate Timer · WebSocket (STOMP) 로컬 테스트

사회자(chairman) / 청중(audience) Pub/Sub 흐름을 한 화면에서 확인합니다. 현재 컨트롤러 인증은 비활성(주석) 상태라 토큰 없이 동작합니다.
※ 같은 페이지를 여러 탭으로 열면 청중 다중 접속을 흉내낼 수 있습니다.
🎙️ 사회자 (Chairman) disconnected
연결 시 /chairman/{roomId} 구독 → 서버의 정보공유 요청 수신
타이머 이벤트 발행 → /app/event/{roomId}
※ FINISHED는 data=null로 전송됩니다 (서버 검증 규칙).
👥 청중 (Audience) disconnected
연결 시 /room/{roomId} 구독 → 사회자 타이머 이벤트 수신.
이 구독이 서버 트리거를 유발해 사회자에게 정보공유 요청이 갑니다.
